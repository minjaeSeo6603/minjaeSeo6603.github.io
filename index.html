How I Work

My workflow is consistent across data science and visualization projects: define the decision question, build an auditable pipeline, stress-test results, and ship clear outputs that others can reproduce.

01

Define Decision-Ready Questions

Translate each project prompt into estimands, outcome definitions, and evaluation criteria before modeling.

02

Build an Auditable Data Layer

Validate raw sources, document cleaning logic, and produce analysis-ready datasets with deterministic scripts.

03

Estimate and Stress-Test Models

Run baseline estimators and robustness checks (DiD, FE, RCT, DML, panel methods) to assess identification risk.

04

Visualize for Interpretation

Convert model outputs into publication-ready figures, effect summaries, and concise narratives for non-technical readers.

05

Package Reproducible Deliverables

Ship write-up, code, and artifacts in rerunnable structures so reviewers can reproduce results end-to-end.
